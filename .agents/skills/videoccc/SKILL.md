# VideoCCC

将用户需求转为可检查的分镜图，再交给执行 Agent 生成动画，并调用本地模型完成配音与字幕。交付真实可播放的成片，不以过程描述、分镜轮播或未渲染代码冒充视频。

本技能仅属于此仓库，不复制或安装到用户级技能目录。若收到的是协调器明确分配的“仅分镜”或“仅执行”阶段任务，只完成该阶段，不递归启动整条工作流。

## 私人工作区

确定当前仓库根目录，读取存在的 `private/local-config.json`，然后为本次工作建立 `private/runs/<run-id>/`。不要沿用其他项目的工作目录。

- 输入、分镜、动画源代码、语音、字幕、帧、视频、运行日志与配置都留在 `private/`。
- 已安装的大模型可以按本机配置从仓库外只读复用，不复制进 Git。缺少依赖时用隔离环境，不修改其他项目或系统 Python。
- 当前需求只授权使用所需的文本与参考素材；不把整个私人目录、密钥或无关文件发送给模型。
- 不在技能、README、提示词日志或命令行中复制 API Key、会话授权令牌；认证交给 CLI 自身配置或安全的环境变量。
- 不自动提交、推送、建群或发布作品。需要分享时使用当前会话已授权的渠道，不复用旧会话的接收人或授权。

## 先确定产物与执行条件

提取主题、受众、画幅、时长、风格、语言、配音偏好、字幕、交付格式与参考图。仅对影响结果的重要缺项提问，其余作合理假设并简述后继续，不要求用户逐步点确认。

默认高清 30 fps，优先让长边达到 1920 像素并保持画幅：16:9 为 1920×1080，4:3 为 1920×1440，竖屏可为 1080×1920。有现有画幅或用户指定尺寸时保持其意图，不拉伸或无说明裁切。

制作前预检：

1. 用本机命令发现方式定位 `codex`、**全局 `deepccc-cli`**、`ffmpeg`、`ffprobe` 和本地 TTS / ASR 环境；查看各自 `--help`。不要把 `deepccc` 的 Web 入口当成终端 Agent，也不要悄悄退回某个 ChatCCC 源码仓库内的副本。
2. 检查显卡、空闲显存与存储。先说明大模型下载等明显耗时步骤；新增付费服务、改变已有配置或越出当前任务授权时先取得方向。
3. 分镜模型默认 **当前账号可用的最新 GPT Sol**。核对官方 OpenAI 模型资料和本机可用模型，按版本与可用性选择真实模型 ID，并在本次清单中记录核验日期。创建技能时的基线 `gpt-6.1-sol` 不是永久默认；`latest-sol` 也不是可直接传给 CLI 的模型名。
4. 若无法核实最新 Sol 或所选模型不可用，明确说明，不能静默换成 Luna、Astra 或其他模型。显式的用户模型选择优先于默认值，不修改全局默认模型。
5. 执行模型默认 `deepseek-v4-flash`，通过本次 CLI 参数选择，继承全局 DeepCCC 的 API 协议、端点与认证，不为此修改全局配置。

只要求改背景、配音、字幕或输出格式时，复用相关产物，只重跑受影响阶段；保留已交付版本作为可恢复副本。

## 分镜 Agent：设计并生成真实图片

默认用 Codex CLI 调用核实后的最新 Sol，在本次私人工作区执行仅分镜任务。向它明确传入主题、风格、素材授权边界、写入目录和不得再委派整条流程的限制。

根据内容决定镜头数量，输出：

- `storyboard/plan.json`：镜头 ID、画面、动作、景别、角色/环境一致性、解说词、预估时长、镜头衔接及可调整项。
- `storyboard/contact-sheet.png` 或必要的逐镜图片：实际生成的视觉分镜，而非仅文字表格。
- 生图提示词与实际采用的模型/工具记录。

Sol 负责设计与调用工具；图片由实际生图工具生成。必须确认工具成功和图片真实存在并查看结果，不能以程序画的占位图冒充“调用生图模型”。缺少生图能力时如实报告；用户未同意前不换云端计费路径或使用不相关模型。

图像应锁定同一角色的轮廓、颜色、服装、道具和场景关系，同时表现动作阶段差异。镜头图是后续动画的视觉依据，不意味着直接把几张图片交替播放就算完成动画。

CLI 调用采用本机实际支持的参数，示意：

```text
codex exec --model RESOLVED_SOL --cd JOB_DIR --json --output-last-message STORYBOARD_RESULT -
```

提示词可经 stdin 传入。将日志保存在本次 `logs/`，只向用户汇报简短状态，不回显原图 base64、完整源码或敏感配置。

## 执行 Agent：全局 DeepCCC 看图制作

将已检查的实际分镜图片与计划交给全局 `deepccc-cli`，而不是只给一句文字描述。使用 `--image` 传入可解析的本地 PNG/JPEG/WebP；调用前检查版本是否支持图片。仅把图片路径写进提示词不等于模型收到了图像。

示意（参数以当前全局 CLI 帮助为准）：

```text
deepccc-cli --stream-json --model deepseek-v4-flash --cwd JOB_DIR --image CONTACT_SHEET --max-steps 32 --prompt EXECUTION_TASK
```

角色、边界、输入/输出路径、字幕/语音工具和验收要求必须写入执行任务。阶段 Agent 不一定继承主会话的技能或权限约束，尤其要显式传递：

- 只操作本次私人工作区，按已批准路径只读访问模型与输入；不读取其他项目、修改全局配置或自行发送文件。
- 不再创建子 Agent，除非用户明确要求额外并行角色。
- 浏览器方式遵守当前环境要求；若被要求连接现有 CDP（例如本机指定端口），不得另开 Chrome/Chromium/Playwright 浏览器。浏览器限制不能靠换 Agent 绕过。
- 不默认添加跳过审批/沙箱的危险参数。失败时只修复具体原因，不能通过扩大权限反复尝试。

记录 CLI 返回的会话 ID。修改同一作品时优先恢复该会话；不要同时向同一个执行会话发起两轮工作。核查图片输入事件或实际能力，不声称未证实的“看过分镜”。

默认生成可编辑的 SVG / HTML / Canvas / Manim 动画源代码，并提供可重跑的构建或渲染方式。根据用户题材选合适表现方式，不将插画代码动画宣称为任意实拍级视频生成。

动作与场景验收重点：

- 动作有关联时共享时间与几何计算，例如脚、腿与踏板保持接触；不要让填色和描边各自运动。
- 有向前移动的意图时，应有地面/围栏等连续视差，不是只有车轮在转；天空和极远海平线可以稳定。
- 循环背景采用可平铺图案与裁剪，验证接缝与缓冲覆盖，不能左右摆动或瞬移复位冒充前进。
- 需要循环时，在回绕前一瞬间与起点比较；只比较正好整周期的两帧会掩盖突跳。

单阶段同一阻碍最多进行两次针对性修复；再次失败就保存已有产物和诊断，报告阻碍及需要的选择，不无限重试或假装完成。CLI 退出码为 0 或返回过程性开场白，不等于产物通过验收。

## 本地配音与字幕

执行 Agent 调用本机模型，而非仅建议调用。优先复用用户已选声音及本机可用的 Qwen3-TTS 等环境；先确认实际 API/CLI，路径来自本机私人配置或预检，不写死开发者电脑路径。

保留原始 WAV、完整文案、声音参数、实际生成时间、采样率和模型版本。用户选择已有样本时优先使用该原始 WAV。新文案若需要稳定声纹，应使用可用的本地克隆/参考提示能力；仅重复 VoiceDesign 描述不保证不同文案完全同一音色，不能假称已锁定声纹。只使用获授权的参考音频。

同一位旁白跨镜头时，优先整段生成再对齐，或复用同一个有效参考提示；不要每个镜头重新随机设计声音，导致角色换声。

字幕优先由 **本地 ASR 或强制对齐模型** 对实际 WAV 给出时间标注，原文案作为文本真值进行纠错；检查专有名词与中文标点。输出 SRT，烧录字幕时可生成 ASS。

- 不以平均字符长度分配冒充准确对齐。若只能结合能量停顿估计分句，说明这是近似方案并征得用户同意后使用。
- 不悄悄把本地 TTS / ASR 改成云端服务。缺失模型时说明需要下载的资源、隔离环境与大致开销。
- 检查非空、有效波形、静音、削波、漏字/重复和末尾截断。试听与客观检查分开汇报，未实际听过不能保证“自然”或“同款”。
- 时长以实际语音为准；调整镜头时长、重写过长文案或经用户认可循环动画，不默认大幅加速声音。

## 高清渲染与成片

从动画源文件直接渲染全彩原始帧，再编码 MP4；**不经 GIF 中转，不把 20 fps 文件重复帧伪装成 30 fps，也不放大低清视频冒充高清**。

对于 SVG SMIL，可暂停后按 `t = frame_index / fps` 精确定位。HTML/Canvas/Manim 应提供等效的确定性时间入口。截图时核查实际 PNG 尺寸，不能只看浏览器视口参数。当前环境若有专用浏览器技能，遵守其连接方式。

按实际语音时间线与镜头计划合成画面、配音和字幕。默认兼容性好的 H.264、yuv420p、AAC、faststart；采用高画质设置并检查文件大小。保留原始帧/WAV，以便按目标渠道重新编码。字幕支持中文字体，位置避让关键动作，用户未要求可关闭字幕轨时优先内嵌保证可见。

交付前验证：

1. `ffprobe` 检查真实分辨率、恒定 30 fps（或用户指定值）、帧数、音轨、时长和大小；视频与音频时间线误差不超过一帧，允许明确记录的结尾静音。
2. 从**编码后的 MP4** 抽取开头、中间、结尾及字幕变化处检查画面，不只看源文件；检查背景确实移动、无空白帧、字幕不溢出或乱码。
3. 完整解码成片排查损坏；核对使用的实际模型与输出路径，不根据设计意图声称已经验收。
4. 保存 `manifest.json`：需求与假设、实际 Agent/模型/版本、阶段状态、输入输出、场景时间、语音/字幕路径、验收结果及失败重试记录；不含凭据。

用户要求发送时再通过当前会话可用且已授权的工具发送，遵守文件大小与格式限制，确认发送成功后再说“已发送”。若仅完成部分阶段或只生成草稿，明确区分，不能报整个制作流程成功。

只清理/结束本次任务创建的临时进程和浏览器标签；保留其他工作及原始素材。制作结果留在 `private/`，不进入 Git 提交。
